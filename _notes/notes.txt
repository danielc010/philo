time_to_die (in milliseconds): If a philosopher has not started eating within
time_to_die milliseconds since the start of their last meal or the start of the
simulation, they die.

time_to_eat (in milliseconds): The time it takes for a philosopher to eat.

time_to_sleep (in milliseconds): The time a philosopher will spend sleeping.

number_of_times_each_philosopher_must_eat (optional argument): If all
philosophers have eaten at least number_of_times_each_philosopher_must_eat
times, the simulation stops. If not specified, the simulation stops when a
philosopher dies.

========== IMPLEMENTATION PLAN ==========

--- DATA STRUCTURES ---

Forget circular linked list — use arrays, simpler and cleaner with threads.

t_fork:
  pthread_mutex_t  mutex

t_philo:
  int              id                  (1-based)
  long             last_meal_time      (ms timestamp)
  int              meals_eaten
  t_fork           *left_fork
  t_fork           *right_fork
  pthread_t        thread
  t_table          *table              (pointer back to shared data)

t_table:
  int              num_philos
  long             time_to_die
  long             time_to_eat
  long             time_to_sleep
  int              must_eat_count      (-1 if not set)
  long             start_time          (ms, set once before threads launch)
  int              simulation_over     (flag: 0 or 1)
  pthread_mutex_t  death_mutex         (protects simulation_over + last_meal_time)
  pthread_mutex_t  print_mutex         (prevents log overlap)
  t_fork           *forks              (array of t_fork)
  t_philo          *philos             (array of t_philo)


--- MUTEX STRATEGY ---

- One mutex per fork (forks[i].mutex)
- death_mutex: protects simulation_over flag and each philo's last_meal_time
- print_mutex: ensures log messages never interleave

Fork pickup order to prevent deadlock:
  Even-numbered philos: pick up left fork first, then right
  Odd-numbered philos:  pick up right fork first, then left
  (breaks the circular wait condition)


--- THREAD STRUCTURE ---

Main thread:
  1. Parse and validate args
  2. Init table, forks, philos
  3. Record start_time
  4. Launch one thread per philosopher
  5. Launch one monitor thread
  6. pthread_join all philosopher threads
  7. pthread_join monitor thread
  8. Cleanup (destroy mutexes, free memory)

Philosopher thread loop:
  while simulation not over:
    pick up forks (in correct order)
    log "has taken a fork" x2
    log "is eating" -> update last_meal_time -> usleep(time_to_eat)
    put down forks
    increment meals_eaten
    log "is sleeping" -> usleep(time_to_sleep)
    log "is thinking"

Monitor thread (runs in parallel):
  while simulation not over:
    for each philosopher:
      lock death_mutex
      check if (now - last_meal_time) > time_to_die
        -> if yes: log "X died", set simulation_over = 1, unlock, return
      check if all philos have eaten must_eat_count times
        -> if yes: set simulation_over = 1, unlock, return
      unlock death_mutex
    usleep(1000)  (check every 1ms)


--- TIMING ---

- get_time_ms(): uses gettimeofday(), returns ms since epoch
- start_time recorded once in main before threads launch
- All timestamps in logs = get_time_ms() - start_time
- ft_usleep(ms): loop with small usleeps + check simulation_over
  (usleep is imprecise for long sleeps, looping is safer)


--- EDGE CASES ---

- 1 philosopher: picks up one fork, can never eat, dies. Must handle gracefully.
- Validate all args are positive integers before starting
- If must_eat_count = 0, stop immediately (or treat as not set — check subject)
- Never print after simulation_over is set
